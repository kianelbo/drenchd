# Drenchd

Drenchd is an offline-first journal for tracking personal substance use. It helps you log what you used, how much, when, and what it cost, then review your patterns over time without needing an account, cloud sync, or a data broker in the middle.

Most tracking apps are built for dashboards, not real life. Drenchd is designed for quick, low-friction logging that fits into the flow of a normal day. Built with Flutter and SQLite, Drenchd keeps everything local on the device so your data stays yours.

## Features

- Daily calendar with color-coded substance summaries
- Custom substance definitions with emoji, color, unit, and notes
- Quantity and cost tracking per intake
- Optional comments on individual entries
- Insights page for total counts, daily activity, and per-substance trends
- Local SQLite storage only
- Cross-platform Flutter app for Android, iOS, macOS, windows, and web

## How to run

```bash
flutter --version   # Flutter 3.24 or newer
flutter doctor
flutter pub get
flutter run
```
